# 烟草收购 Android App

面向烟草收购/销售场景的离线安卓应用。支持收烟、卖烟、本单自定义价格、烟草图片编辑、快捷筛选、数量统计、历史订单和小票打印。

## 已实现

- 收烟 / 卖烟业务切换
- 每款烟支持默认价格和本单自定义价格，不区分散户/大户
- 点击烟草图片可修改价格、数量，并从系统相册更换图片
- 支持名称搜索、品牌快捷筛选和仅查看已选烟草
- 独立记账：人员姓名、备注、头像，我收钱/我付钱、今日收入支出结余和历史记录
- 统计分析：今天、近7天、本月、全部和自定义日期筛选，收支饼图和品牌条形图
- 独立烟价管理：新增烟草，维护商品图片、名称、单位、参考价、默认收烟价和默认卖烟价
- 大字收烟登记：按烟草名称快捷筛选，仅调整本单价格和数量，手机和平板自适应布局
- 统一客户管理：客户头像、姓名、电话和备注同时用于交易结算与拖拽记账，旧往来人员自动合并
- 扫码枪录入：每款烟维护唯一条码，收烟或卖烟时扫码后直接填写本单数量和价格（支持得力 HID 键盘模式扫码枪）
- 入库与结算拆分：登记入库只记录烟草品类和数量，结算时再逐款填写价格并生成正式交易
- 统一业务入口：首页和管理模式均使用“登记入库 → 结算”，隐藏旧的收烟/卖烟直接开单入口
- 极简首页：默认只显示“登记入库”和“结算”，长按首页 App 图标进入完整管理功能
- 入库购物车：扫码或选择的烟草先进入清单，保存前可修改数量、删除；扫码枪输入完成后自动识别
- 文字清单导入：支持“红南京35条”这类多行文本，名称无需匹配商品库或条码
- GitHub 在线更新：通过 Release Asset API 与附件 CDN 下载，支持连接状态、自动重试、取消和失败后重新下载
- 结算自动打印：优先使用设置中的默认蓝牙打印机，缺少配置、权限或连接失败时再显示打印选择窗口
- 商品分类与排序：烟价管理支持自定义分类、分类筛选，并可长按拖拽调整商品顺序
- 品牌化 UI：界面采用与 App 图标一致的酒红、奶油白和金色视觉体系
- 完整设置：店铺与小票信息、58/80mm纸宽、默认打印机、管理密码、包含图片的数据备份与恢复
- 红南京、炫赫门、玉溪、利群初始商品
- 订单结算与本地离线保存（最多保留最近 200 单）
- Android 系统打印
- 已配对蓝牙 ESC/POS 热敏小票机打印（默认 GBK 中文编码）
- 历史小票查看和重新打印

## 运行

1. 使用 Android Studio 打开本目录。
2. 使用 JDK 17，并等待 Gradle 同步完成。
3. 连接 Android 8.0 及以上真机或模拟器，运行 `app`。
4. 蓝牙打印前，在手机系统设置中先完成打印机配对；Android 12 以上首次查找时允许“附近设备”权限。

命令行环境具备 Android SDK 和 JDK 17 时，也可执行：

```bash
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

本机开发环境已于 2026-07-29 完成真实构建验证。

## 数据说明

当前首版是单机离线版，数据保存在应用私有存储。卸载应用会清除数据。商品包装为原创示意图，实际使用时可替换为已获授权的商品照片。
