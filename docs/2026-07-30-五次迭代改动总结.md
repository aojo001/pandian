# 五次迭代改动总结

日期：2026-07-30

## 1. 烟草、交易与客户模块完善

- 烟草编辑移除分类选择，只保留图片、名称、单位与价格。
- 交易类型统一为“收烟 / 卖烟”。
- 放大收烟登记中的文字、金额、数量按钮和结算按钮。
- 新增客户管理，支持头像、姓名、电话、备注和搜索。

## 2. 图片来源选择

- 烟草图片、客户头像、记账客户头像支持拍照。
- 支持从相册或文件选择图片。
- 使用 Android `FileProvider` 安全共享临时拍照文件。

## 3. 日常操作精简

- 首页只突出收烟/卖烟登记、记账、烟价和客户四个高频功能。
- 交易记录和数据统计改为紧凑入口。
- 删除收烟页面冗长说明和废弃占位页面。

## 4. 客户数据统一

- 客户管理成为唯一客户资料来源。
- 交易结算和拖拽记账共用客户头像、姓名、电话和备注。
- 旧记账往来人员按 ID 或姓名迁移、合并到客户管理。

## 5. 拍照返回修复

- 修复启动相机前关闭照片弹窗，导致结果监听器被注销的问题。
- 相机或文件选择完成后再关闭来源弹窗，确保图片能够被接收和保存。
- 声明相机硬件为非必需，确保没有相机的平板仍可安装并使用文件选择。

## 验证方式

- 执行 `./gradlew assembleDebug` 编译 Android 调试包。
- 分别从烟草、客户和记账编辑页面进入照片来源弹窗。
- 验证拍照返回后图片预览更新，并可保存资料。
- 验证取消拍照、取消文件选择时页面不会写入无效图片。
